# NAOSIQ - Flujo UX e identidad v6

Paquete de revision de producto. No es una aplicacion implementada ni un archivo nativo de Figma.

Empieza por START_HERE.md. El visor HTML funciona como simulador documental y usa datos ficticios. Los botones de las pantallas estan enlazados al panel de acciones. Los formularios representados no guardan datos de negocio.

Contenido: 118 pantallas SVG, 363 acciones, 32 recorridos, tokens de marca, documentos PDF, modelos de vouchers, contratos y tareas de migracion. Los escenarios de error y demora preservan las reglas del proyecto.

Manual recibido en references. El logo incluido es provisional; no se comparten archivos de fuente.
